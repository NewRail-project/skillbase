# User Interface Components

Этот каталог содержит все компоненты пользовательского интерфейса.

## Структура

- `pages/` - Страницы приложения
- `editor/` - Компоненты редактора тестов
- `authContext.js` - Контекст аутентификации

## Использование

Все компоненты должны быть адаптивными и работать без JavaScript.
