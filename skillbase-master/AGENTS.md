# AGENTS.md

## Цель проекта
Создание веб-приложения с использованием минималистичного стека, ориентированного на мобильные устройства.

## Стек
- **Frontend**: Vanilla JS
- **Backend**: Firebase Auth / Firestore
- **Deployment**: GitHub Pages

## Структура папок
- `/core`: Основная логика приложения.
- `/docs`: Документация проекта.
- `/shared`: Общие компоненты и утилиты.
- `/ui`: Пользовательский интерфейс.

## Правила
1. **Мобильный экран**: приоритет в дизайне и разработке.
2. **Промпты**: строго один промпт за один раз.
3. **Версионирование**: коммит после каждого этапа разработки.
4. **Безопасность**: правильные ответы не должны храниться в публичных данных теста.

## Сроки
- **Демо**: за 2 недели.
- **Ограничения**: Live-комнаты НЕ входят в MVP.
