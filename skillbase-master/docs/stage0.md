# Stage 0: Project Foundation

## Overview
This is the initial stage where we establish the project foundation and define the technical stack.

## Technical Stack
- **Frontend**: Vanilla JavaScript (no frameworks)
- **Backend**: Firebase (Authentication, Firestore)
- **Deployment**: GitHub Pages
- **Mobile Priority**: Mobile-first design approach

## Project Structure
- `core/` - Core application logic
- `docs/` - Documentation
- `shared/` - Shared components and utilities
- `ui/` - User interface components

## Stage 0 Rules
1. Mobile screens have priority
2. One prompt at a time
3. Commit after each stage
4. Correct answers should not be stored in public test data
5. Demo within 2 weeks
6. Live rooms are NOT included

## Development Process
This project follows a staged approach where each stage builds upon the previous one.
