# Core Application Logic

Этот каталог содержит основную логику приложения.

## Структура

- `auth.js` - Аутентификация пользователя
- `editor.js` - Создание и редактирование тестов
- `import/parser.js` - Парсер текста тестов
- `quiz.js` - Прохождение тестов
- `assign.js` - Назначение тестов
- `grading.js` - Проверка ответов (будет реализовано)

## Использование

Все модули должны быть изолированы от UI и использовать async/await для асинхронных операций.
