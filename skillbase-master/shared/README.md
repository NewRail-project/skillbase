# Shared Components

Этот каталог содержит общие утилиты и компоненты, используемые во всем приложении.

## Файлы

- `firebase-config.js` - Конфигурация Firebase
- `firebase.js` - Инициализация Firebase
- `app.js` - Маршрутизация приложения
- `main.js` - Точка входа приложения
- `utils.js` - Утилиты для форматирования и debounce

## Использование

Все файлы в этом каталоге являются частью общей архитектуры приложения и не должны изменяться без согласования с командой.
