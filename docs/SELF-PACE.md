# Доработка: палитра гостя, свой темп, вердикт, топ, админ

## Решения
- **Вердикт без ключа (вариант B, без Blaze).** Ведущий проверяет ответ у себя и пишет
  `rooms/{код}/verdicts/{uid}` (`v: {qid: {c, p}}`). Читает только сам игрок. Ключ ответа
  никому не раскрывается; правильные ответы в «своём темпе» открываются после завершения теста.
  Нужна открытая страница ведущего (как и для очков раньше).
- **Мгновенный вердикт:** в «своём темпе» всегда; в синхронном автономном режиме — флажок
  при создании комнаты (по умолчанию выкл: сосед по парте видит «неверно» и отсекает вариант).
- **Админ** проходит тест участником чужой комнаты (флаг `isAdminPlayer`), в общий рейтинг,
  табло и подиум не попадает (виден только себе). Ведущий и участник одной комнаты — разные роли.

## Модель «в своём темпе»
`mode:"auto"`, `pace:"self"` (дубль в `settings.pace`). Лента игрока: `players/{uid}/shown/{n}`
(`at` — серверная метка, create-only, лента строго по порядку, поле `prev`).
Ответ принимается `questionSec` после `shown.at` + 1 с. Ветка отделена: `hostSelfDuties`,
`selfLiveInfo`; `autoPlan/finalizablePositions` для таких комнат не используются.

## Рейтинг
Запись `scores`/`verdicts` пакетами (`writeBatch`), запуск через 350 мс после снапшота ответа;
тикер лишь страхует раз в 2 с.

## Проверка перед деплоем
`npm test`, `node scripts/check-imports.mjs`, `npm run test:rules` (нужен `firebase login`).
