# Доработки по сценарию (предметы → тема → теория → тест → Live)

- `core/pair-grade.js` — оценка за пару: 90·P/M + 10·A/N, без скорости и места; «0» без ответов, «Не участвовал» для отсутствующих; журнал по алфавиту; ручная правка только с причиной и автором.
- `core/live-report.js` — подробный отчёт по сохранённым ответам: статистика группы, анализ вопросов (верно/неверно/пропуски/время/частая ошибка), анализ учеников, готовность по темам, рекомендации.
- `ui/components/live-report.js` + правки `ui/pages/room.js` — итоговый экран: название → подиум → полный рейтинг → подробный отчёт → журнал. Состояние раскрытого отчёта сохраняется при обновлении данных, перезагрузки страницы нет.
- `ui/pages/quiz.js` — тест с `requireMaterial` закрыт для ученика до прочтения теории.
- Темы готовности берутся из необязательного поля `topic` у вопроса.
- `tests/pair-grade.test.js` — 9 тестов.

## Второй проход
- Live: рейтинг — постоянный DOM-узел, переезжающий между видами (карточки не пересоздаются, FLIP работает); отчёт и журнал обновляются на месте.
- Редактор теста: выбор предмета, темы, теории и «обязательно изучить теорию».
- Предмет → тема раскрывается: теория (книга/PDF), тесты, «Запустить в Live», «История и оценки».
- `#test-history/<id>`: статистика, оценки, готовность и вывод «нужно ли ещё занятие» для обычного теста.
