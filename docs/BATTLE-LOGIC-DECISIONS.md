# Командная битва — решения по пунктам ТЗ §31 (ПРЕДЛОЖЕНИЯ, нужно утвердить)

Реализованы в `core/battle-logic.js` и покрыты `tests/battle-logic.test.js`.
Если решение не нравится — меняется в одном месте, тесты укажут, что сломалось.

1. **Множественный выбор, штраф 125%.** Один верный вариант = 4 «кванта»,
   неверный = −5 квантов (1,25 × 4). Доля = max(0, 4·верных − 5·неверных) / (4·n).
   Целые числа, без накопления ошибки округления; итог в [0..1]. Штраф настраивается
   (`wrongPenalty`). Пример ТЗ: верные A,B,C; выбрано A,B,D → (8−5)/12 = 0,25.
2. **Скорость при частично верном множественном ответе.** Скоростной компонент =
   20% × доля оставшегося времени × **доля правильности**. Неверный ответ скорости
   не получает; частично верный — пропорционально.
3. **Ничья голосов при одиночном выборе, капитан не решил за 15 с.** Случайного
   выбора нет: ответа команды нет, правильность/скорость/командный бонус = 0,
   участие проголосовавших сохраняется.
4. **Ручной выход игрока.** Выход самим игроком — те же 60 с (`manualLeaveGrace`);
   «Выбыл» по решению преподавателя — немедленно (`eliminatePlayer`).
5. **Канат.** Положение = clamp((A−B)/scale, −1, 1), scale = очки за вопрос ×
   max(3, ⌈вопросов/2⌉). Для CSS `ropePercent`: 50 — центр, границы 8..92.
6. **Статистика голосов.** Не хранится в виде «кто за что» в снимке: в снимке —
   доли личной правильности по раундам и итоговые проценты. Срок хранения
   подробных голосов не задан — требуется решение владельца.

Дополнительно (не было в ТЗ явно):
- Процент подготовки = 70% точность + 30% участие (по доступным вопросам).
- «Результат команды» в личной оценке = очки своей команды / очки лучшей команды.
- Капитанство при выбывании: игрок команды с лучшим Live; **вновь вышедший
  запасной не наследует его автоматически** (§6.3), но может получить, если в команде
  больше никого нет.
- Командный бонус: ≥80% проголосовавших ответили **полностью** верно.
- Ничья за 1-е место у троих и более при выборе капитанов → «Дуэль» за обе позиции.
